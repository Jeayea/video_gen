# 拍什么：适合本项目的素材推荐

挑素材时看三件事：**版权干净**、**角色少、场景集中**（参考图锁得住）、**不容易触发视频模型的内容审核**。
下面每一条都按这三点筛过，并写明它在这套流程里的难点。

## 推荐清单

| 方向 | 素材 | 为什么合适 | 难点 / 风险 |
|---|---|---|---|
| 非遗 | **《天工开物·杀青》造竹纸**（宋应星，1637） | 原文就是分步骤的工艺流程，原书 5 幅插图正好对应 5 个段落；以旁白为主，没有多角色音色不一致的问题；场景图 / 道具图能派上用场 | 工具（抄纸帘、楻桶、水碓、焙墙）模型没见过，要靠道具图和逐镜描述；工艺细节要人工考证 |
| 非遗 | 《天工开物》其他篇：「陶埏」制瓷、「乃服」织造、「作咸」制盐、「五金」冶铸 | 同上，都是流程 + 原书插图 | 冶铸、火器类画面有火光、熔融金属，模型容易画得失真 |
| 历史 | **《史记·廉颇蔺相如列传》**（完璧归赵 → 渑池之会 → 负荆请罪） | 三幕结构完整，冲突靠对白推进；主要角色 3~4 个，定妆照锁得住；没有血腥场面 | 对白戏要解决角色音色（见下面第 3 条）；战国服饰、宫室要考证 |
| 历史 | 张骞通西域、郑和下西洋（史书原文 + 白话旁白） | 旁白为主，地点变化大，画面丰富 | 场景多，每换一个地点就要一张场景图；船队、大场面费秒数 |

## 选材时的讲究

1. **版权**：中国作品的著作权保护到作者去世后 50 年（沈从文 1988 年去世，仍在保护期）。
   外国名著要用公版译本，或者自己翻译，因为**译文本身也有版权**。古籍原文是公版，
   但现代点校本的标点、注释可能有版权，引用原文时以古本为准。
2. **旁白为主的题材最省事**（非遗、历史介绍）：只有一个旁白音色，H3 原生音频
   「每个片段换一个嗓子」的问题被直接绕开。可以只把视频原声当环境音
   （`COMPOSE_AMBIENT_MODE=under`），旁白用 TTS。
3. **对白为主的题材**（小说、列传）要接受角色音色问题：H3 原声在不同片段之间不会保持同一个嗓子
   （见 AGENTS.md「原声引导配音」）。要么用原声引导重配（`AUDIO_DUB_GUIDE=native`，
   每个角色音色固定），要么用普通 TTS。
4. **非遗 / 历史类的事实要人工核对**：AI 画出来的工艺步骤、器物形制、朝代服饰可能不对
   （例如明代纸工被画成清代辫子）。先找原书插图、博物馆资料、非遗纪录片，把关键画面的描述写准。
5. **先拍一场再拍全片**：H3 $0.13/秒，60 秒成片约 $8，3 分钟约 $25。先用一场（12~15 秒，约 $2）
   验证人物、场景、声音，再决定拍不拍完整篇。
